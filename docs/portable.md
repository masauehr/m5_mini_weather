# 移動式（ポータブル）運用

最初は**持ち歩いて測る**使い方から始める。固定設置・防水化（[waterproof.md](waterproof.md)）は将来の話。
参考: note「第2層ポータブル気象観測所」（歩きながら記録し、スマホで天気予報と並べて見る）。

> 状態: 設計メモ。実機・実測は未実施。

## 1. 使い方のイメージ

- CoreS3 に ENV III を Grove ケーブルでつなぎ、手に持つ／カバンの外側に付けて歩く。
- 画面に現在値を表示しつつ、SD に記録、BLE でスマホにも送る（現在の実装のまま使える）。
- 帰宅後（または外出先）にスマホ・SD からCSVを取り込み、[analysis/](../analysis/README.md) で見る。

## 2. 固定設置との違い

| 項目 | 移動式 | 固定設置（将来） |
|---|---|---|
| 記録間隔 | 短め（10〜30秒）が向く。移動で値が変わるため | 1分 |
| 電源 | **内蔵電池**（USB給電なし） | USB給電 |
| 画面 | 点灯（見て使う） | 消灯 |
| 防水・百葉箱 | 不要（**雨天は使わない**） | 必要 |
| 気象庁との比較 | 地点が違うので**そのままは使えない** | 最寄り地点と比較 |
| 位置 | 動くので**位置の記録が重要** | 固定 |

## 3. 測るときの注意（値がずれる原因）

| 原因 | 対策 |
|---|---|
| **体温・手の熱**（ENV III を握る・ポケットに入れる） | センサーを体から離し、**外気に触れる位置**に出す。Groveケーブルで本体と離して持つ |
| **本体の自己加熱**（画面・CPU・充電） | ENV III を本体から離す。長時間の連続点灯で上がりやすい |
| **直射日光**（日向と日陰で大きく変わる） | センサーは日陰側に。日向を測るときは、そう記録に残す |
| **応答の遅れ**（場所を変えた直後は前の環境の値が残る） | 場所を移したら**数十秒〜数分待ってから**読む（実機で応答時間を確認） |
| **風・移動**（動くと空気が当たり、熱が逃げて安定しやすい） | 静止測定と比べて差が出るかを記録 |
| **雨・結露** | **雨天・濡れた場所では使わない**。ENV III は防水ではない。ビニール袋で密閉すると通気がなくなり湿度・気圧が狂うので不可 |
| **動作温度** 0〜40℃（公称・[waterproof.md](waterproof.md) 参照） | 真夏の車内・冬の屋外など範囲外では測定値を参考扱いに |

## 4. 電源の目安

- 内蔵電池 500mAh。画面点灯・通常動作で消費は**約100mA級（概算・要実測）**なので、**数時間**が目安。
- 外出が長いなら、モバイルバッテリー（USB）をカバンに入れてつなぐ。ただし充電中は本体が熱くなり、気温に影響する。
- 電池残量は CSV の `battery_pct` に記録される。

## 5. 位置の扱い（公開に注意）

- 現在のCSVには**位置が入っていない**。移動式では「どこで測ったか」が解析の鍵になる。
- 方針案: **スマホ側の位置ログ**（地図アプリの履歴など）と**時刻で結びつける**。時刻はISO 8601（タイムゾーン付き）で記録済みなので、後で結合できる。
- 本体にGPSは付けない（まず時刻での結合で足りるか見る）。
- **位置データ・自宅周辺の記録は公開リポジトリに載せない**（`data/` はgit除外）。公開する図や例は、場所を特定できない形にする。

## 6. 持ち出しチェックリスト

- [ ] CoreS3 の電池残量（または、つなぐモバイルバッテリー）
- [ ] SDカード（FAT32）が入っている
- [ ] 時刻が合っている（起動時にRTC/NTP。外出先で電源が落ちた場合は時刻を確認）
- [ ] ENV III が体・日向・本体から離れる持ち方になっている
- [ ] 雨の予報がない（ある場合は持ち出さない）
- [ ] スマホで受信ページ（Bluefy）が開ける
