# 機材・配線

> 数値は公式ドキュメントでの確認が必要な項目を含む。実機で確認できたら「確認済み」に更新する。

## 構成

| 機材 | 役割 |
|---|---|
| M5Stack CoreS3 | 本体（ESP32-S3、画面、SDスロット、Wi-Fi/BLE、バッテリー内蔵） |
| ENV III Unit | 温湿度（SHT30）＋気圧（QMP6988）センサー |
| microSDカード | ログ保存（FAT32） |
| USB-Cケーブル | 書き込み・給電 |
| Groveケーブル | CoreS3 Port A ↔ ENV III |

## ENV III

| センサー | 測定 | I2Cアドレス（一般的な値） |
|---|---|---|
| SHT30 | 温度・湿度 | 0x44 |
| QMP6988 | 気圧（温度補正用に温度も出力） | 0x70 |

- 接続: CoreS3 の **Port A（赤・I2C）** にGroveケーブルで接続。
- アドレスは実機で I2C スキャンして確認する（確認済み: 未）。

## ライブラリ（候補）

| ライブラリ | 用途 |
|---|---|
| M5Unified / M5GFX | CoreS3の画面・電源・RTC等の統一API |
| M5Unit-ENV | ENV III（SHT3x/QMP6988）の読み取り |
| NimBLE-Arduino | BLE（Phase 2・省メモリ） |

## 注意点

- **自己加熱**: 本体の発熱でセンサーの温度が上振れする。ケーブルで離す・間欠測定にする・気象庁データと比較して補正する、のいずれかを検討。
- **気圧は絶対値**: 海面更正は行わず、まず観測値（hPa）のまま記録する。標高補正は解析側で行う。
- **時刻**: 電源断で時刻が狂うため、起動時にNTP（Wi-Fi）等で合わせ、CSVには必ず時刻を入れる。
- BLEは ESP32-S3 の **BLE（Low Energy）のみ**。Bluetooth Classic（SPP）は使えない。
