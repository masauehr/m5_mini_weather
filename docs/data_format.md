# データ仕様

## 測定項目

| 項目 | 単位 | 備考 |
|---|---|---|
| 温度 | ℃ | SHT30 |
| 湿度 | %RH | SHT30 |
| 気圧 | hPa | QMP6988（海面更正なし） |
| 電池残量 | % | 任意（屋外化で重要） |
| 記録間隔 | 秒 | その行を記録したときの記録間隔（`interval_s`）。間隔が混在しても欠測を正しく判定するため |
| マーク | 整数 | 「ここから測る」の印（`mark`）。印を付けた行だけに電源投入後の連番（再起動で1に戻る）。通常の行は空欄 |

## 記録周期

- 既定: **60秒**（参考記事と同じ）。**10秒 / 30秒 / 60秒**から選べる。
- 切替: 本体画面下部の右のボタン「EVERY ◯s」をタップするたびに 10 → 30 → 60 → 10 … と切り替わる。**画面下部の領域のみ反応**（持ち歩き中の誤操作を避けるため）。切替直後にすぐ1回測定する。
- 設定は電源を切っても保持される（Preferences）。
- 移動式では短め（10〜30秒）、固定設置では60秒が目安（[portable.md](portable.md)）。

## CSV形式（SDカード・スマホ共通）

ファイル名: `YYYYMMDD.csv`（日付ごとに分割）。文字コードは UTF-8、改行は LF。

```csv
timestamp,temp_c,humidity_pct,pressure_hpa,battery_pct,interval_s,mark
2026-11-21T09:00:00+09:00,24.31,61.2,1012.45,87,60,1
2026-11-21T09:01:00+09:00,24.33,61.0,1012.43,87,60,
```

- 時刻は **ISO 8601（タイムゾーン付き）**。
- センサー読み取り失敗時は値を空欄にして行は残す（欠測と区別するため）。
- ファイルの1行目はヘッダー。新規ファイル作成時のみ書く。
- `interval_s`・`mark` 列は2026-11-21に追加（末尾）。それ以前の形式（5列・6列）のCSVも解析側は読める（欠測判定は既定の60秒）。同じ日のファイルに形式を混ぜない。

## マーク（「ここから測る」の印）

- 本体画面下部の左のボタン「MARK」をタップすると、**その場ですぐ1回測定**し、その行の `mark` 列に連番を入れる。画面のSD行に `M<回数>` を表示する。
- 場所を変えたとき・測り始めに押す。解析では印を区間の開始として区間ごとに集計できる（`analysis/segments.py`）。
- 番号は電源投入後の連番で、再起動で1に戻る。解析は番号ではなく**時刻順**で区間を数える。
- 位置はCSVに含まれない。場所との対応は、印の時刻とスマホの位置ログ等で後から結びつける（[portable.md](portable.md)）。

## BLE 仕様（Phase 2）

スマホは iPhone 15 Pro。Safari は Web Bluetooth 非対応のため、**Bluefy**（App Store）で `web/index.html`（公開URL: <https://masauehr.github.io/m5_mini_weather/web/>）を開いて使う。

- デバイス名: `M5MiniWeather`（アドバタイズにサービスUUIDを含める）
- 文字コード: UTF-8、1通知 = CSV 1行（改行なし）。MTU は iOS が自動で拡張する（要求185）

| 種別 | UUID | 属性 | 内容 |
|---|---|---|---|
| Service | `b5dcd81f-8818-4a59-8055-4be29e1ab1ab` | - | 気象観測サービス |
| Current | `93201d96-eec6-4b2f-a728-2fd5f41d8512` | Read / Notify | 現在値（CSV 1行。記録間隔ごとに更新・通知） |
| LogControl | `cfb36b51-d385-497f-ad44-3f4b9bf0e9b6` | Write | コマンド（下記） |
| LogData | `d6ee814f-18a7-4682-9420-06a34fc0a78a` | Notify | ログ行。末尾に `END`（該当日なしは `NOFILE`） |

### コマンド（LogControl に書き込む）

| コマンド | 動作 |
|---|---|
| `DATE,YYYYMMDD` | その日のCSV（ヘッダー行含む）を LogData に1行ずつ通知し、最後に `END` |

- 取得は日単位。スマホ側で日付ごとのCSVを結合する。
- 送信中は測定を一時停止する（1日分で十数秒）。
- 認証・暗号化は未導入（Phase 2 後半で検討）。通知の内容は気象値のみで、位置情報は含めない。

## 取り扱い

- 実測CSVは `data/` に置き、**git管理しない**。
- 公開する場合は位置・設置場所が分からない形（日時のずらし・サンプルデータ化）にする。
