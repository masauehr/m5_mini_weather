# データ仕様

## 測定項目

| 項目 | 単位 | 備考 |
|---|---|---|
| 温度 | ℃ | SHT30 |
| 湿度 | %RH | SHT30 |
| 気圧 | hPa | QMP6988（海面更正なし） |
| 電池残量 | % | 任意（屋外化で重要） |

## 記録周期

- 既定: **1分ごと**（参考記事と同じ。変更可能にする）

## CSV形式（SDカード・スマホ共通）

ファイル名: `YYYYMMDD.csv`（日付ごとに分割）。文字コードは UTF-8、改行は LF。

```csv
timestamp,temp_c,humidity_pct,pressure_hpa,battery_pct
2026-11-21T09:00:00+09:00,24.31,61.2,1012.45,87
2026-11-21T09:01:00+09:00,24.33,61.0,1012.43,87
```

- 時刻は **ISO 8601（タイムゾーン付き）**。
- センサー読み取り失敗時は値を空欄にして行は残す（欠測と区別するため）。
- ファイルの1行目はヘッダー。新規ファイル作成時のみ書く。
