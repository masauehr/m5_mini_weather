# m5_mini_weather（M5Stack ミニ気象観測所）

M5Stack CoreS3 + ENV III で気温・湿度・気圧を測り、スマホへ転送して解析するプロジェクト。将来は防水仕様に拡張する。
リポジトリ: https://github.com/masauehr/m5_mini_weather（公開） / ローカル: `~/projects/m5_mini_weather`

## 現在の状態

- 2026-11-21 開始。Phase 0完了。**Phase 1のファームウェアを実装し、PlatformIOでビルド成功**。実機未入手のため動作確認は未実施。
- スマホ: iPhone 15 Pro。BLE（NimBLE）で現在値通知＋日単位ログ取得。受信は Bluefy で `web/index.html` を開く（Web BluetoothはHTTPS必須。GitHub Pages配信: https://masauehr.github.io/m5_mini_weather/web/）。Wi-Fiは起動時のNTPのみ。
- 気象庁比較: AMeDASの過去データは約1週間強しか取得できないため、実測は期間内に `analysis/compare_jma.py` で取得・キャッシュする。地点IDと標高は引数で渡しリポジトリに書かない。
- **運用形態: 最初は移動式（持ち歩き）**。注意（体温・自己加熱・日向・雨天不可）と課題（記録間隔の切替・マーク機能）は `docs/portable.md`。固定設置は将来。
- 百葉箱（将来の固定設置用）: IIJ「MITSUHA DIY 簡易百葉箱」（記事＋製作ガイドPDF）に準拠。長鉢5・6号と鉢皿5・6号の二重筒＋ステンレスボルト、約1,700円（2021年）。ポール固定を基本（スタンド版は風で倒れるため風のない場所のみ）。ENV IIIは内筒内のポールに固定し、ケーブルは下皿との隙間から屋内へ。
- 屋外化: 公称動作温度が 0〜40℃（ENV IIIは0〜60℃の記載もあり）で、氷点下・炎天下は仕様外。センサーのみ百葉箱で屋外・本体は屋内（案A）から段階的に進める（Stage 0〜3）。
- 開発環境: PlatformIO（Arduino + M5Unified）。手順は `firmware/README.md`。初回ビルドはツールチェーン取得で約12分・約5GB。

## 要点

- ENV III = SHT30（温湿度）+ QMP6988（気圧）。CoreS3 の Port A（I2C）に接続。
- 記録は1分周期・CSV（`YYYYMMDD.csv`、ISO 8601時刻）。実測データは `data/` に置きgit除外。
- リスク: 本体の自己加熱、屋外での日射による上振れ（参考記事で約15℃差）、防水と通気の両立。
- 参考記事: note「第2層ポータブル気象観測所」（Core2+BLE+SD）、IIJ「簡易百葉箱」（日射対策）。

詳細はリポジトリの `plan.md` と `docs/` を参照。
