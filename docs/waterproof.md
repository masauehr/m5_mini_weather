# 防水・屋外化の設計メモ（Phase 4）

データ取得（Phase 1〜3）が安定してから着手する。ここは設計の下調べ。

## 課題

| 課題 | 内容 |
|---|---|
| 日射 | 直射でセンサーが熱せられ気温が大きく上振れする |
| 雨・結露 | 本体・コネクタへの浸水 |
| 通気 | 湿度・気圧を測るため完全密閉できない |
| 電源 | 屋外でのバッテリー持ち・充電 |
| 固定 | 風で飛ばされない・ポールへの取付 |

## 参考: 簡易百葉箱（IIJ Engineers Blog）

水田センサーを冬のビニールトンネルで使ったところ、日射の影響で気象庁データより15℃以上高い値が出た。植木鉢を使った自作の簡易百葉箱で対策した事例。

- 内筒（長鉢5号）＋外筒（長鉢6号）の二重構造で自然通風・日射を遮る。
- 鉢皿を下（照り返し防止）と上（日よけ・降雨対策）に使う。
- 錆びにくい **ステンレス製ボルト・ナット** で固定。
- 部材費は約1,700円。ポールにサドルバンドで固定。
- 日射の影響を完全には除去できない点も記載あり。

→ 本プロジェクトでも、まず**センサーだけを外に出して百葉箱内に置く**構成が有力。

## 構成案

1. **本体は屋内/防水ボックス、ENV IIIのみ屋外**（延長Groveケーブル）
   - 自己加熱も避けられる。ケーブルの防水貫通（グロメット）が必要。
2. **全体を防水ケースに収め、センサー部だけ通気＋防水膜**
   - 防水透湿フィルタ（ベントプラグ等）の利用を検討。

## 検討事項

- 防水等級（IPxx）の目標を決める。
- ENV III 自体は防水ではないため、水が直接かからない百葉箱内に置く。
- 湿度センサーは結露で劣化・誤差が出るため、長期の乾燥復帰を確認する。
- 低消費電力化（スリープ＋間欠測定）とバッテリー/ソーラー。

## 試験項目（予定）

- 簡易百葉箱あり/なしで気象庁データとの差を比較
- 雨天・結露環境での動作と復帰
- 1週間以上の連続屋外試験
