# 防水・屋外化の設計（Phase 4・将来の固定設置用）

> **まだ着手しない。最初は移動式（持ち歩き）で運用する → [portable.md](portable.md)。** この文書は、将来固定設置するときの設計メモ。

> 状態: **設計（実機・屋外試験は未実施）**。数値のうち出典のないものは「概算」「要確認」と明記する。
> 設置場所が推定できる情報（住所・地点ID・標高など）はこの文書に書かない。

## 1. 目標と優先順位

屋外化の目的は「防水」そのものではなく、**屋外で正しい気温・湿度・気圧を長期間取り続けること**。

| 優先 | 目標 | 理由 |
|---|---|---|
| 1 | **測定が正しい**（日射・本体の熱の影響を受けない） | 参考記事では日射で約15℃上振れした。防水しても測定が狂えば意味がない |
| 2 | **壊れない**（降雨・結露・高温低温で故障しない） | 電子部品・リチウム電池の保護 |
| 3 | **止まらない**（電源が続く） | 欠測を減らす |
| 4 | 簡単に作れる・直せる | 個人で作る前提。部材は入手しやすいもの |

防水の目標は **降雨・飛沫に耐える（IPX4相当）** とする。水没・高圧洗浄は対象外。
ただし湿度・気圧を測るため、**センサー部は密閉せず通気させる**（防水と通気の両立が設計の核心）。

| 項目 | 内容 | 出典・状態 |

| CoreS3 電池 | 500mAh（本体内蔵のリチウム電池） | [公式](https://docs.m5stack.com/en/core/CoreS3) |
| CoreS3 動作温度・スリープ電流 | 本体の値は確認できず。軽量版 CoreS3 SE は動作温度 0〜40℃、待機約 105µA（電池・参考値） | [SE公式](https://docs.m5stack.com/en/core/CoreS3-SE)・**要確認（実測する）** |

**結論**: 冬の氷点下・夏の炎天下は、ENV III も CoreS3 も**仕様外**になり得る。
- 仕様外の期間の測定値は「参考値」として扱い、解析側でフラグを付ける。
- リチウム電池は一般に**氷点下・高温での充電は不可**。屋外で電池充電を行うなら、本体を日陰・断熱側に置き、温度を実測して判断する。

## 3. 構成案の比較

| 案 | 構成 | 長所 | 短所 |
|---|---|---|---|
| **A 本体屋内＋センサーのみ屋外** | ENV III だけ延長ケーブルで屋外の百葉箱へ | 本体・電池を守れる。自己加熱を避けられる。電源は屋内（USB） | 窓・壁にケーブルを通す必要。ケーブル長に制限 |
| B 全体を屋外の防水ボックス | CoreS3 を防水ボックスに入れ、ENV III は百葉箱へ | 設置場所の自由度が高い | 仕様外温度・結露・電池の問題が出る |
| C 全体を密閉 | 1つの密閉ケースにすべて | 作るのが簡単 | **湿度・気圧が正しく測れない／内部が高温になる**（不採用） |

**採用方針: 段階的に A → B と進める。**

| 段階 | 内容 | 完了条件 |
|---|---|---|
| Stage 0 | 屋内で実機確認。自己加熱を評価（本体とセンサーを離す前後の差） | 画面点灯時・消灯時の温度差を数値化 |
| Stage 1 | **案A**: 百葉箱（センサーのみ）を屋外、本体は屋内 | 1週間、気象庁（AMeDAS）との気温差が日中に拡大しない |
| Stage 2 | **案B**: 本体も防水ボックスで屋外（日陰側）、USB給電 | 雨天を含む2週間、浸水・結露なし |
| Stage 3 | 電池／ソーラー駆動 | 目標期間（暫定1週間）電源が続く |

## 4. 日射・通風対策（簡易百葉箱）— IIJ「MITSUHA DIY 簡易百葉箱」を基本にする

百葉箱は [IIJ Engineers Blog の記事](https://eng-blog.iij.ad.jp/archives/10519)と、その[製作ガイド（PDF・18ページ）](https://eng-blog.iij.ad.jp/wp-content/uploads/2021/08/1f584ef64a457e721892e5f46bf70da1.pdf)に沿って作る。
ガイドの図・写真は IIJ の著作物なので**転載しない**。ここには要点と、本プロジェクト向けの変更点だけを書く。詳しい寸法・写真は必ずガイドを見ること。

> 注意: このガイドは **LoRaWAN センサー（LP-01、LAS-603V2）用**で、ENV III 用ではない。ENV III に合わせた変更点は 4.4 にまとめる。
> ガイド自身も、**日射の影響は完全には除去できない**、厳密な気温測定には農研機構の標準作業手順書を参照するよう述べている。

### 4.1 仕組み

- 長鉢（内筒・外筒）と鉢皿（傘・下皿）を重ねた**二重筒**。下から入った空気が筒の中で温められて上へ抜け、**自然に気流が起きて**日射による上昇を抑える。
- 傘（鉢皿）が日射と雨を避け、**下皿が地面の照り返しを防ぐ**。内筒の周囲にはアルミホイルを巻いて日射を反射する。
- IIJ の検証では、晴れて気温が近い日で、百葉箱の有無で**約15℃の差**が出た（2月、ビニールトンネル内）。

### 4.2 構成は2種類（ガイドより）

| | 杭打ち設置（ポール） | スタンド設置 |
|---|---|---|
| 場所 | 杭を打てる地面など | 杭を打てないコンクリート面など |
| 強風 | ○ | **× 風で倒れる。風のない場所のみ** |
| 移動のしやすさ | △ | ○ |

本プロジェクトは屋外（ベランダ・庭）を想定するので、**ポール固定を基本**にする。
スタンド版は風のない場所（屋根下など）でのみ使う。ポールを床や柵に固定できないベランダでは、風対策を別途検討する。

| ⑤ | 六角ボルト 全ねじ M8×60mm | 1 | ポールへの差し込み用 |

### 4.4 製作の流れ（ガイドの要点・言い換え）

1. **下皿（③）**: 中央にポールを当てて外径をなぞり、その大きさまで穴を広げる。ポールが通り、上下に簡単に動かない程度にする（広げすぎると固定できない）。
2. **内筒（①）**: 逆さにして中央に穴を開け、⑤のボルトを根本まで差し込む。⑦のナットで裏側から固定し、さらにもう1個の⑦と⑧をボルト先端で互いに噛み合わせて固定する。アルミホイルを2枚に分けて左右から筒のカーブに合わせて巻き、はみ出しを切ってセロハンテープで留める。
3. **外筒（②）**: 中央にボルト穴を開け、内筒の径の範囲内に**3〜4か所**のねじ穴を内筒と同じ位置に開ける（両方の底面を密着させてキリで貫通させると位置が合う）。⑥のボルトを**内筒とは逆に下から**差し込み、⑨のタッピングねじを1cmほど残して垂直にねじ込む。
4. **外筒を内筒に固定**: ねじ先を内筒の穴に挿してから、順番に少しずつねじ込む。外筒と内筒が**平行**になるよう注意し、ねじ先が内筒の内側に少し出る程度でよい。先端が抜けたら全部戻してやり直す。
5. **傘（④）**: 中央にボルト穴を開け、外筒の上からかぶせ、ボルト先端が少し出るまで差し込み、⑦のナットで固定する。
6. **ポールに固定**: センサー側を先にポールに固定し、ケーブルは日よけと下皿の間を通す。日よけは⑧がポールの内径に近ければかぶせるだけ。強風で飛ぶ恐れがあれば、短く切ったガムテープを⑧に巻いて太さを調整し、上から差し込む。ポールは地面に刺すか、柵に結束バンドで固定する。

### 4.5 ENV III に合わせた変更点（本プロジェクトの設計）

| 項目 | IIJ（LP-01） | 本プロジェクト（ENV III） |
|---|---|---|
| センサー | LP-01 のセンサーボックスをサドルバンドでポールに固定 | **ENV III をポールに固定**（サドルバンド・結束バンド等。壁に触れさせない）。小型なので内筒に収まる想定（要確認） |
| 通信部 | 通信ボックスを別のポールの高所へ（アンテナのため） | **CoreS3 は屋内**（案A）。Groveケーブルを延ばして屋内へ。BLEはスマホが近くにある前提で、距離は問題にならない |
| ケーブル | 日よけと下皿の間を通す | 同じ経路。**ドリップループ**を作って水を切る。コネクタは百葉箱の内側・下向きにし、横殴りの雨で濡れる位置に置かない |
| 湿度 | LP-01 は相対湿度の測定に非対応 | ENV III は湿度も測る。**結露・濡れ**の影響を試験で確認する（9. 試験計画の「結露復帰」） |
| 気圧 | 対象外 | ENV III の気圧センサーは外気に通じていないと正しく測れない。百葉箱は通気があるので問題ない想定 |
| 防虫 | 記載なし | 通気口（下部の隙間）に**防虫ネット**を検討（通気を妨げない範囲で） |

**ガイドから変える点は最小限**にして、IIJ の検証結果（日射抑制の効果）が当てはまりやすいようにする。変更した部分は、気象庁比較で効果を確認する。

### 4.6 設置位置

- 高さ: ガイドには数値の記載がない。一般に**地上 約1.25〜2m（WMOの推奨範囲・要確認）**。ベランダでは手すりより上、床の照り返しから離す。
- 壁・屋根・**エアコン室外機・換気扇**から離す（排熱・排気の影響）。風通しの良い場所。**日射が直接当たる金属・コンクリートの近くは避ける**。
- 固定: ポールをサドルバンド・結束バンドで固定し、風で飛ばされない強度を確保する。

## 5. 防水・配線設計

### ENV III（センサー部）
- ENV III 自体は防水ではない。**百葉箱の内側に置き、雨が直接かからない**ことを前提にする。
- ケーブルは**ドリップループ**（下に垂らして最下点から水を切る）を作り、伝い水が筐体に入るのを防ぐ。
- 結露でセンサーが濡れた後に**乾燥して復帰するか**を試験で確認する（湿度センサーは結露・汚染で劣化・誤差が出る）。

### 本体（案Bの場合）
- 筐体: **IP65程度の樹脂ボックス**（購入時に等級を確認）。本体は日陰側に置く。
- ケーブルの引き込みは**ケーブルグランド**（PG7/PG9等）で防水する。コネクタ部は防水ではないため、グランドの内側（箱の中）に置く。
- 内部には**乾燥剤**。温度変化による結露に備え、**防水透湿の通気プラグ（ベント）**の併用を検討。
- USBポート等の開口は塞ぐ。画面・ボタンは屋外では使わない（後述の消費電力対策と合わせて画面は消灯）。

### I2C 延長
- Grove ケーブルを延長する場合、ケーブルが長いほど信号が鈍る。まず **1m 以内**、I2C は 100kHz に下げて試す（現在のコードは 400kHz。延長時は下げる設定を追加する）。
- 数m以上は I2C エクステンダ（差動方式）等が必要になる可能性がある。**実機で確認する**。
- 外部用のケーブルは屋外対応（被覆の紫外線耐性）のものを選ぶ。

## 6. 電源設計

CoreS3 の電池は 500mAh。目標を「**1週間無給電**」とすると、**平均 約3mA 以下**（実効容量を8割として約2.4mA）が必要になる。

| 状態 | 消費の目安 | 備考 |
|---|---|---|
| 画面点灯・通常動作 | 約100mA級（SEの仕様値が約110mA。参考） | 電池で約5時間 |
| 画面消灯・Wi-Fi OFF・BLEのみ | **要実測** | 現在のコードは画面が常時点灯。まず消灯で実測する |
| ライトスリープ活用 | **要実測** | 1分周期の測定の間に眠らせる。BLE接続中は眠れない点に注意 |

方針:
1. **Stage 1・2 は USB 給電**（屋内のACアダプタから低電圧のUSBケーブルで引き込む。100V機器を屋外に出さない）。
2. 電池・ソーラーは Stage 3 で、**実測した平均電流に基づき**容量とソーラーパネルを決める。
3. 電池残量は CSV に記録済み（`battery_pct`）。電池電圧の低下による測定誤差もログで追う。

## 7. 測定品質の確保

| 課題 | 対策 | 確認方法 |
|---|---|---|
| 本体の自己加熱 | ENV III を本体から離す（案A）。画面消灯 | Stage 0 の温度差測定 |
| 日射による上振れ | 百葉箱。設置位置の選定 | 気象庁比較（日中の気温差が拡大しないか） |

## 9. 試験計画

| 試験 | 方法 | 合格基準 |
|---|---|---|
| 自己加熱（Stage 0） | 本体直付け／延長ケーブルで離す／画面消灯、で温度を比較 | 差を数値化し、離した状態で本体の影響が許容範囲 |
| 日射（Stage 1） | 百葉箱あり／なしを並べ、気象庁比較で日中の差を見る。IIJの検証（晴天で約15℃差）と同じ見方 | 日中の気温差が夜間より拡大しない |
| 組立の確認 | 外筒と内筒が平行か、傘・ボルトの緩み、ENV III が壁に触れていないか、ケーブルのドリップループ | 目視・揺すって緩みなし |
| 散水（防水） | 筐体にホースで全方向から約10分散水 | 内部に水・結露なし |
| 結露復帰 | 雨天・朝露後の湿度の推移を確認 | 乾燥後に正常値へ復帰 |
| 長期（Stage 2〜） | 2週間→1か月の連続運用 | 取得率 99%以上、浸水なし |
| 温度範囲 | 設置場所の実測最低・最高温度と仕様の突き合わせ | 仕様外の時間割合を把握 |

## 11. リスクと安全

| リスク | 対策 |
|---|---|
| リチウム電池の発熱・膨張 | 屋外・高温・氷点下での充電を避ける。日陰・断熱。膨らんだら使用中止 |
| 屋外の電気 | 100V電源を屋外に出さない。屋内のUSBアダプタから低電圧で引き込む |
| 強風・落下 | 固定強度の確認。落下物の危険がない場所に設置 |
| 他人の敷地・共用部 | 設置してよい場所か確認する |
| 公開情報 | 設置場所・地点IDをリポジトリに書かない |

## 12. 未決事項

- 設置場所の条件（ベランダ・庭・ポールなど）と、電源を取れるか。ポールを固定できない場所の風対策（スタンド版は風のない場所のみ）
- ポールの寸法（鉢皿の穴と皿ばね付きナットに合うもの。ガイドに数値なし）
- 目標期間（暫定: 1週間→1か月→長期）と、冬の氷点下の扱い
- 屋外用筐体の購入先と等級の確認
- CoreS3 本体の動作温度・スリープ電流の公式値の確認
